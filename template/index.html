Craft Apps Online

Logiciels open source d'ArtCraft, à utiliser directement dans le navigateur, sans installation. Les fichiers ouverts restent dans votre navigateur : rien n'est envoyé sur un serveur.

Site non officiel. Ces logiciels sont l'œuvre de l'équipe d'ArtCraft, que nous remercions chaleureusement pour son travail et pour le choix de le partager en open source. Ce site n'est ni édité ni soutenu par ArtCraft : il lance simplement leurs versions officielles dans le navigateur, pour les postes et appareils où l'installation classique n'est pas possible. Si vous pouvez installer des logiciels, préférez les versions de bureau sur getartcraft.com.

Bon à savoir

  • Premier lancement : l'application se télécharge (10 à 90 Mo selon l'outil). Ensuite, elle est gardée en cache et s'ouvre vite, même hors connexion.
  • Installer comme une application (PWA) : dans Edge ou Chrome, ouvrez l'outil, puis cliquez sur l'icône « Installer » à droite de la barre d'adresse. Aucun droit administrateur n'est demandé.
  • Ouvrir et enregistrer : « Ouvrir » utilise le sélecteur de fichiers du navigateur, « Enregistrer » télécharge le fichier.
  • Maturité : ces logiciels sont jeunes et évoluent souvent ; le site suit automatiquement chaque nouvelle version. Gardez une copie de vos documents importants avant de les modifier.

Merci à l'auteur

Ces logiciels, leurs icônes et tout le travail qu'ils représentent sont l'œuvre de l'équipe d'ArtCraft (storytold), qui les publie gratuitement en open source. Un grand merci pour ce travail remarquable et pour le choix de le partager avec tous.

Ce site n'a rien créé de ces outils : c'est seulement une interface pour lancer leurs versions officielles dans un navigateur, sans installation. Pour suivre le projet, signaler un problème ou soutenir l'auteur, rendez-vous sur getartcraft.com et sur les dépôts GitHub de chaque application.
